# Сборка и запуск в Windows

Приложение работает на Windows 10/11 x64. IFC обрабатывается локально; установленная программа не требует Node.js или доступа в интернет. Геометрия заказчика в публичный код не включена: после запуска выберите свой IFC.

## Скачать готовое приложение

Откройте [Releases → v0.3.0](https://github.com/Sviridov001/neapolis-solar/releases/tag/v0.3.0). В разделе **Assets** доступны:

- [Neapolis-Solar-0.3.0-Portable.exe](https://github.com/Sviridov001/neapolis-solar/releases/download/v0.3.0/Neapolis-Solar-0.3.0-Portable.exe) — без установки.
- [Neapolis-Solar-0.3.0-Setup-x64.exe](https://github.com/Sviridov001/neapolis-solar/releases/download/v0.3.0/Neapolis-Solar-0.3.0-Setup-x64.exe) — установщик.
- [Neapolis-Solar-0.3.0-Windows-x64.zip](https://github.com/Sviridov001/neapolis-solar/releases/download/v0.3.0/Neapolis-Solar-0.3.0-Windows-x64.zip) — полный комплект для распаковки.
- SHA256SUMS.txt — контрольные суммы.

Для загрузки публичного Release вход в GitHub не требуется.

## Готовые файлы из GitHub Actions

1. Откройте вкладку **Actions** репозитория `Sviridov001/neapolis-solar`.
2. Выберите workflow **Windows application** и последний успешный запуск для версии 0.3.0. При необходимости используйте **Run workflow → main → Run workflow**.
3. Внизу страницы скачайте артефакт **Neapolis-Solar-Windows-x64** и распакуйте его. Для скачивания артефакта требуется вход в GitHub.
4. Выберите один из вариантов:
   - **Portable.exe** — один файл без установки. При запуске распаковывает Electron во временную папку, настройки/кеш хранит в профиле пользователя.
   - **Setup-x64.exe** — мастер NSIS с выбором папки, ярлыками в меню «Пуск» и на рабочем столе. Установка для текущего пользователя без повышения прав.
   - **Windows-x64.zip** — распакуйте весь архив в постоянную папку и откройте `Neapolis Solar.exe`; DLL и ресурсы должны оставаться рядом.

CI создаёт SHA256SUMS.txt. Он помогает проверить целостность скачанного файла, но не заменяет подпись издателя. EXE пока не подписан сертификатом; запуск и установка на настоящей Windows ещё требуют отдельной проверки. Если политика компьютера запрещает неподписанные приложения, потребуется подписанная сборка или согласование с администратором.

## Локальная сборка

Установите Node.js 24 и Git. В PowerShell:

```powershell
git clone https://github.com/Sviridov001/neapolis-solar.git
cd neapolis-solar
npm ci
npm test
npm run test:desktop
npm run package:win
```

Файлы появятся в `release/`. Для быстрого запуска из исходников: `npm start`. Только Portable: `npm run package:portable`. Первая сборка скачивает Electron и инструменты упаковки и требует интернет. Закреплённые версии зависимостей находятся в package-lock.json; для сборки используйте `npm ci`.

## Проверка готового пакета

- Открыть IFC через кнопку импорта и через **Файл → Импорт IFC / Ctrl+O**.
- Проверить север и размеры, выбрать минимум два окна через Ctrl + щелчок.
- Рассчитать выделенную группу, затем весь список; проверить CSV и сохранение JSON.
- Перемещать время, включить и отключить солнечный сектор, суточную траекторию и модель солнца.
- Проверить меню, повторный запуск, сохранение файлов, установку/удаление Setup.

Portable проверен сборкой в Linux, тестами геометрии и локального сервера. CI собирает установщик на Windows. Прохождение сборки не означает прохождения визуального теста на рабочем компьютере.

## Дальнейший выпуск

Перед распространением широкой аудитории: проверить пакет на чистой Windows, добавить иконку, настроить подпись Authenticode и проверять опубликованные сборки перед широким распространением. Автоматическое обновление пока не включено.
