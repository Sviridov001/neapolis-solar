Для окна — точка на внешней поверхности. Для площадки — горизонтальная сетка на указанной отметке.

Добавьте окно или площадку в сцене.

Метод и ограничения

Геометрическая видимость центра солнечного диска. Положение солнца: SunCalc 1.9.0. Трассировка лучей по непрозрачной геометрии; прозрачные материалы исключаются. Произвольный объект окна не гарантирует правильную классификацию стекла.

Продолжительность оценивается по серединам временных шагов. Короткие интервалы меньше шага могут быть пропущены. Это предварительный анализ внешних точек, без нормативной оценки помещений, облачности и отражений.

Окружение учитывается только при наличии в модели. Север и координаты должны быть проверены пользователем.

БЫСТРЫЙ СТАРТ

От модели — к солнечным интервалам

  1. Проверьте координаты, север и размеры. Инструмент «Размер» измеряет расстояние между двумя точками.
  2. Нажмите «Окно / точка», затем на видимую внешнюю поверхность окна. Точка создаётся в месте нажатия, с отступом 2 см наружу. Это не нормативная расчётная точка помещения.
  3. Для площадки нажмите «План», затем «Площадка». Задайте отметку, обведите контур и нажмите «Завершить».
  4. Ctrl + щелчок по окнам в сцене или строкам списка добавляет и снимает выделение. Обычный щелчок оставляет одну точку. Точки сохраняются при снятии выделения; повторный Ctrl + щелчок по тому же окну не создаёт дубликат.
  5. Подтвердите север и размеры, выберите дату. «Рассчитать выделенные» обрабатывает только текущее выделение; «Рассчитать все точки» — весь список. Каждый запуск заменяет предыдущие результаты.
  6. Выберите точку. Нажимайте на шкалу результата: красный луч покажет препятствие, жёлтый — открытое солнце.

«Плоскость луча» — полупрозрачное вертикальное сечение через активную точку и текущий азимут солнца. Оно поворачивается вместе с временем. Золотая суточная траектория показывает направления на солнце над геометрическим горизонтом для выбранной даты. Все дневные лучи в общем случае не лежат в одной плоскости.

На существующем IFC окна распознаны по именам объектов. Другие модели могут потребовать ручного выбора точки. Наличие и полноту окружения проверяйте отдельно.

Изменение исходных параметров делает предыдущий расчёт неактуальным. При смене модели выбранные точки очищаются.

План для проверки севера и размеров

Сверяйте направление стрелки с геометрией здания, а не с краями листа. Референсы не совмещены с IFC автоматически.
